# RepoLens

![CI](https://github.com/apothemm/repo-lens/actions/workflows/ci.yml/badge.svg)

TypeScript / Node.js 24. Локальная инвентаризация исходников: языки, объём файлов, крупнейшие файлы и ошибки чтения.

## Возможности

- Рекурсивный обход без перехода по символическим ссылкам.
- Сводка расширений и объёма, список крупнейших файлов.
- Исключает `.git`, `node_modules`, `.venv`, `bin`, `obj`, `build`, `dist`, `target`.
- JSON в stdout; содержимое файлов не читается и не отправляется.

## Запуск

```text
node src/cli.ts ./repository --top 10
node --test tests/*.test.mjs
```

## Проверки

GitHub Actions выполняет сборку и тесты. Тесты находятся в исходниках репозитория и работают на временных данных.

## Ограничения

Расширения — приближение к языкам, а объём — размер файлов, а не число строк. Игнорирование `.gitignore` не поддерживается. Node 24 запускает TypeScript через встроенное удаление аннотаций типов.

Предложения и ошибки — в Issues. Лицензия MIT.
